# OCR 标注与验证循环

对一张图片做 OCR 标注，并通过视觉回环验证结果是否忠实于原图。

## 何时使用

- 用户要求对已有 OCR 结果做验证、校对、检查标注是否正确。
- 用户要求你对某张图片做 OCR / 识别文字或表格。

## 核心循环

对每张待处理图片，执行以下循环（最多 4 轮，防止死循环）：

1. **标注**：读取原图，产出 OCR 结果。
   - 若内容是普通文本：输出纯文本，保留原文换行与段落。
   - 若内容是表格：判断表格的对齐结构，输出 HTML，**只允许 `<table>` `<tr>` `<td>` 三种标签**，不得出现 `<th>`、`<thead>`、`<tbody>`、`colspan`、`rowspan`、`style`、`class` 等任何其他标签或属性。每行单元格数应一致。若原图中存在明确的列对齐结构（如序号列、数值列、编码列等），**必须拆分为独立的 `<td>` 单元格**，不得用空格模拟对齐。


2. **渲染**：把本轮标注结果写入临时文件（`./ocr_resp.html` 或 `./ocr_resp.txt`），用 `render_ocr.py` 渲染成图片（`./ocr_render_roundN.png`）。除最后一轮外，每轮循环结束后，用 `rm -f` 删除本轮产生的临时文件和渲染图片。

3. **对比**：把渲染图与原图并排对比，逐项分析差异。

4. **判定**：
   - 若差异**仅为表现层**（字体、字号、颜色、单元格边框粗细、行高、对齐、留白、抗锯齿等），说明内容已忠实 → **结束循环**。
   - 若存在**内容差异**（缺字/多字、错字、数字/编号错误、单元格错位、行列数不符、漏行漏列、文本顺序错误等）→ 进入下一轮，把【渲染图 + 原图 + 上一轮 OCR 结果】一并作为输入重新标注，重点修正上一轮发现的内容差异。

## 渲染工具用法

render_ocr.py 位于 skill 同级目录。调用时先确定 skill 所在目录，再用相对路径调用：

```bash
# SKILL_DIR 指向本 SKILL.md 所在目录（即 ocr-validate/）
# 临时文件写入项目工作目录，渲染输出轮次编号递增（round1, round2, ...）

# 表格
SKILL_DIR="$(cd "$(dirname "$0")" && pwd)"
echo "<table>...</table>" > ./ocr_resp.html
python "$SKILL_DIR/render_ocr.py" --type table --text-file ./ocr_resp.html --out ./ocr_render_round1.png

# 文本
echo "..." > ./ocr_resp.txt
python "$SKILL_DIR/render_ocr.py" --type text --text-file ./ocr_resp.txt --out ./ocr_render_round1.png

# 每轮循环结束后，删除本轮临时文件和渲染图
rm -f ./ocr_resp.html ./ocr_resp.txt ./ocr_render_round1.png
```

脚本仅依赖 matplotlib + Pillow，自动选用 CJK 字体渲染中文。输出 PNG 路径打印到 stdout。

## 对比要点

读取原图与渲染图后，按下列顺序核对，只要任一项不符即判为内容差异：

- **表格**：行数、每行列数是否与原图一致；单元格内容逐格比对；空单元格位置是否对应；数字与编号是否正确且无重复/错位。
- **文本**：逐句比对有无错字、缺字、多字；段落与换行顺序是否一致；标点是否遗漏。

渲染图的字体、网格线样式、留白与原图不同属正常，**不作为重标注的理由**。

## 结束与产出

循环结束后，向用户报告：最终的 OCR 结果、共迭代了几轮、每轮修正了哪些内容差异、以及最后一轮判定为"仅表现层差异"的依据。

> 注意：渲染脚本是为人工/模型视觉回环服务的，渲染样式不追求像素级还原原图排版，只用于暴露内容层面的差异。
